# Субдоминанта гармоническая - нижние ноты 1, 5 и 4

У нас есть четыре ноты: нижняя тоника, верхняя тоника, доминанта и субдоминанта.
Вы должны угадать какие две из них звучат одновременно.

В этом уроке 12 упражнений.
В первых четырёх упражнениях нижняя нота - 1.
В следующих четырёх - 5.
И еще в  четырёх - 4.
